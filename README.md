# Pro Work - Household Service Booking Application

Pro Work is a web application designed to simplify the process of booking household services such as electricians, plumbers, and priests. It allows users to book daily services easily, and provides multiple payment methods for secure transactions. 

In addition to helping users, Pro Work also offers a platform for service workers to list themselves and offer their skills to earn money. Workers can choose from various service categories to provide their expertise and get hired for extra work.

## Features

### User Features:
- **Browse and Book Services**: Users can browse available services (electrician, plumber, priest, etc.) and book them for household needs.
- **Multiple Payment Methods**: Secure and easy payments via various available methods like Credit/Debit Cards, Wallets, and more.
- **Service Scheduling**: Users can choose time slots for the services and track their bookings.
- **Booking History**: Users can view past bookings and track the status of active ones.

### Worker Features:
- **Register as a Worker**: Users who want to provide services can list themselves as a worker by signing up on the platform.
- **Choose Service Categories**: Workers can select from a list of service categories (electrician, plumber, priest) they wish to offer.
- **Make Money**: Workers can earn money by accepting job offers based on their skillset.

## Tech Stack

- **Frontend**: React.js, HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Payment Gateway**: Razorpay
- **Hosting**: Deployed on Hostinger
